# MG Physio Center

واجهة موقع مركز MG Physio Center باللغة العربية، متوافقة مع الموبايل، وتشمل:
- الصفحة التعريفية والخدمات.
- قسم Women's Health Physiotherapy.
- صورة فريق المركز.
- نموذج طلب حجز يفتح WhatsApp برسالة جاهزة (المريض يراجعها ويرسلها بنفسه).
- لوحة عرض تجريبية للمالك والدكتور والمريض (`dashboard.html`).

## تشغيل محلي
افتح `index.html` في المتصفح. انتقل إلى لوحة العرض من رابط «لوحة النظام».

## النشر على GitHub Pages
1. أنشئ Repository جديدًا على GitHub باسم `mg-physio-center`.
2. ارفع جميع الملفات والمجلدات الموجودة هنا إلى جذر المستودع، مع الحفاظ على مجلد `assets` ومجلد `.github`.
3. من Settings ثم Pages اختر **GitHub Actions** كمصدر النشر.
4. انتظر انتهاء عملية النشر، ثم افتح رابط GitHub Pages الظاهر في صفحة Pages.

## ما الذي يعمل حاليًا؟
- الموقع واجهة ثابتة قابلة للنشر.
- نموذج الحجز يجهّز رسالة WhatsApp؛ لا يخزّن الحجز في قاعدة بيانات ولا يرسل الرسالة تلقائيًا.
- `dashboard.html` نموذج واجهات وبيانات تجريبية فقط. تغيير الدور ليس تسجيل دخول حقيقيًا، والتعديلات لا تُحفظ مركزيًا.

## قبل الاستخدام الحقيقي
GitHub Pages يستضيف ملفات الواجهة الثابتة فقط. لا تضع كلمات مرور أو مفاتيح سرية أو بيانات مرضى في ملفات HTML/JavaScript أو GitHub. لتفعيل حسابات حقيقية وصلاحيات منفصلة للمالك والدكاترة والمرضى، وحفظ الحجوزات والملفات الطبية، نحتاج Backend وقاعدة بيانات آمنة (مثل Supabase مع سياسات RLS مضبوطة ومختبرة)، ثم ربط الإشعارات. إرسال WhatsApp تلقائيًا يحتاج خدمة خادمية وتكامل WhatsApp Business Platform. لا تستخدم بيانات مرضى حقيقية في النسخة الحالية.
